# SillyTavern 角色卡管理器 · Android

> 把 SillyTavern 的**卡片库 / 世界书 / 预设**搬进手机，直接用系统文件夹读写，不依赖桌面端、也不需要自建服务器。

**版本** `v1.10.26` · **包名** `com.sillytavern.cardmanager.android` · **平台** Android 7.0+ (API 24) · **许可** MIT

本仓库是**移动端**（Capacitor + Vue 3）；配套的桌面版（Electron）在独立仓库中维护。

---

## ✨ 核心亮点

| 亮点 | 说明 |
|------|------|
| **真·本地文件操作** | 通过系统 SAF 目录树授权直接读写卡片文件，**不需要存储权限、不需要 root**，与桌面酒馆共用同一份目录 |
| **万卡库性能优化** | 轻量缓存 `.jskzx_cache.json` 二次启动秒开（零扫描零读文件）；搜索倒排索引分块构建；列表增量渲染 |
| **内置测卡引擎** | 在手机上真实调用 API 试卡：预设 → 世界书 → 正则 → 插件 → MVU 变量 → EJS 模板，全链路可调 |
| **MVU 变量可视化** | 把 AI 输出的变量指令渲染成**可折叠树**，支持直接编辑 / 重命名 / 删除 / 新增 / 撤销 / 重置 |
| **预设条目可管理** | 导入预设后不再是黑盒：逐条查看、编辑、开关、克隆，并保证开关真正影响生成 |
| **8 套主题** | 白昼 / 暗夜 / 青灰 / 古风 / 汉风 / 未来 / 赛博朋克 / 水墨，每套含独立配色、字体、圆角、装饰 |

## 📚 卡片库

**加载与刷新**
- 选择卡片库目录（SAF 授权，记住上次选择）
- 下拉刷新；重新扫描
- 授权失效时提示重新授权，并区分「首次授权」与「授权失效」

**分组**
- 以子文件夹作为分组；支持全部 / 未分类 / 各分组切换
- 长按菜单可将卡片**移动到分组**；批量模式下可**批量分组**

**查找**
- 搜索范围：名称 / 简介 / 触发词 / 标签 / 文件名
- 筛选：全部 · 有世界书 · 有正则 · 标签分类 · 未分类 · 管理分组
- 排序：含「📥 导入最新」等
- 视图模式：平铺 / 网格 / 海报 / 翻页
- 分页器 + 每页条数可调

**导入**
- **本地导入**：调起系统文件选择器**多选** `.png` / `.webp` / `.json` → 复制入库（**同名跳过，绝不覆盖**）
- **网址导入**：填 `.png` 直链直接下载入库
- 导入后可自动按规则打标（可在设置中关闭）

**单卡操作**（长按卡片）
多选 · 移动到分组 · 创建物理副本 · 导出 · 定位文件 · 重命名 · 删除

**批量操作**（长按 → 多选进入）
批量标签 · 批量分组 · 批量 AI 打标 · 批量导出 ZIP（可分享）· 批量推送 · 批量删除

**更多工具**（右上「更多」）
角色宇宙图谱 · 查重 · 从网址导入 · 批量导出 ZIP

> **卡片格式支持**（SillyTavern 标准）
> - **JSON**：`chara_card_v1` / `chara_card_v2` / `chara_card_v3`
> - **图片卡**：PNG / WebP / JPEG —— 自动提取内嵌的角色元数据（PNG 走 `tEXt`/`iTXt` 的 `chara` 块；非标准或损坏的图片会退回**深度扫描**提取有效 JSON）
>
> ```bash
> # 库扫描规则：.json 走文本解析，其余文件一律按图片卡尝试提取 chara 元数据
> ```

## 🧪 测卡（核心功能）

在手机上把一张卡真正「跑起来」，验证预设、世界书、正则、插件的组合效果。

### 配置
- 扫描预设目录 / 从文件导入预设 / 粘贴预设 JSON 导入
- **📝 预设条目**：列出当前预设全部提示词条目
  - 展开编辑：名称 / 角色（system · user · assistant）/ 正文
  - 开关：控制该条是否参与生成（同步 `prompt_order` 与条目自身，保证真正生效）
  - 删除（二次确认）/ 新增 / **克隆**（深拷后保序插到原条目后）
  - 改动实时持久化，重启后保留
- 预设参数：Temperature / Max Tokens / Top P / Top K / 惩罚项 / Max Context，可一键重置为预设默认值

### 正则插件
- 汇总三类正则：角色卡内嵌 · 预设内嵌 · 插件携带，逐条可开关
- 插件列表可开关、删除、文件导入、粘贴 JSON 导入

### 世界书
- 条目开关（常驻标记可见）
- 展开可改触发词 / 内容 / 插入位置，改动同步回卡片世界书

### 变量（MVU）
- 引擎开关：MVU 变量系统 · EJS 模板引擎 · 分段渲染
- **变量树**：可折叠树形渲染，按类型着色（数值 / 文本 / 布尔 / 对象 / 数组）
  - 搜索路径或值 · 一键展开收起 · JSON 源码入口（高级批量粘贴）
  - 节点操作面板：**编辑值**（类型自动识别）· **重命名** · **复制路径** · **删除此变量** · **新增子项**
- 更新日志（OpLog）：按 AI 楼层记录变量变更
- 撤销 / 重置

### 聊天 / 设置
- 多会话管理（新建 / 切换 / 重命名 / 删除）
- API 配置、回复条数、用户名与人设、记忆开关与条数、最大楼层
- 记忆表格查看器：类型筛选 · 行编辑 · 删除 · 清空

## ❓ 常见问题

**Q：选了目录却看不到卡片？**
确认所选目录下确实有 `.json` / `.png` / `.webp` 角色卡；选到空目录会提示重新选择。

**Q：导入卡片没反应 / 数量没变？**
同名文件会被**跳过**（设计如此，绝不覆盖已有卡片）。提示会显示「导入 N 张 · 跳过同名 M 张」。

**Q：测卡说没有 API？**
需要在「设置 → 聊天测卡 API」配置端点、Key、模型（支持 OpenAI 与 Anthropic 兼容协议）。

**Q：Android 模拟器启动后卡死、adb 一直 offline？**
这是 **emulator/adb 对非 ASCII（中文）路径的兼容问题**：把 Android SDK 放到纯英文路径，或建一个 ASCII 目录联结再调用，例如：

```powershell
New-Item -ItemType Junction -Path "E:\AndroidSDK" -Target "<真实的 SDK 路径>"
$env:ANDROID_SDK_ROOT = "E:\AndroidSDK"
```

**Q：预设里的条目开关点了没效果？**
本版本已修复：酒馆预设的 `prompt_order` 有「扁平」与「嵌套（character_id）」两种形态，现均兼容，且开关会同时写回条目自身与 `prompt_order`。
