## 阶段 0：已知问题修复（7 BUG）

### BUG 0.1 主题切换没有效果（优先修复，因它掩盖乱码/对比类观感问题）

**根因（已确认）**：`js/mobile/theme.js` 的 `applyTheme` 只在 `<html>` 加 `theme-dark`/`dark` 类，但**全项目无任何 `.theme-dark{--van-*}` CSS 变量覆盖**（grep 确认仅 theme.js 3 处引用）→ Vant 组件配色从未变化，只变了 body 背景。

**修复**：新增移动端深色变量集（`entry.js` 移动端分支引入或追加至 `css/style.css`），覆盖 Vant 全套变量：
```css
html.theme-dark {
    --van-background: #101014;            --van-background-2: #1b1c22;
    --van-text-color: #e4e4e7;            --van-text-color-2: #a1a1aa;
    --van-gray-1: #1b1c22;                --van-gray-2: #26272e;
    --van-gray-3: #34363f;                --van-gray-5: #52525b;
    --van-gray-6: #8b8b95;                --van-border-color: #34363f;
    --van-cell-background: #1b1c22;       --van-popup-background: #16171c;
    --van-nav-bar-background: #16171c;    --van-tabbar-background: #16171c;
    --van-field-input-text-color: #e4e4e7;
    --van-button-default-background: #26272e;   --van-button-default-border-color: #34363f;
    --van-action-sheet-background: #16171c;     --van-empty-description-color: #8b8b95;
}
```
（清单以 `vant/lib/index.css` 实际变量为准可整段覆盖；设置页开关逻辑已正确无需改。）

**验收**：开启深色后全部 Vant 组件即时变深、重启记住、系统栏图标同步；为 0.4/0.5/0.7 提供正确的观感基线。

### BUG 0.2 打开后屏幕不能上下滑动

**根因**：详情页 `van-tabs` 只写了 `.detail-page :deep(.van-tabs__content){flex:1;overflow-y:auto}`，**未给 tabs 根节点 `flex:1;min-height:0;overflow:hidden`** → tabs 高度由内容撑开，超出部分被 `.mobile-shell{overflow:hidden}` 裁剪，整体无法滚动。

**修复**（`CardDetailView.vue` 样式补齐高度链路）：
```css
.detail-page :deep(.van-tabs) { flex: 1; min-height: 0; display: flex; flex-direction: column; overflow: hidden; }
.detail-page :deep(.van-tabs__content) { flex: 1; min-height: 0; overflow-y: auto; }
.detail-page :deep(.van-tab__panel) { min-height: 100%; }
```
其余页面滚动容器已核实为 `flex:1;min-height:0;overflow-y:auto`（js/mobile 全目录无 `height:100%` 陷阱，仅 MobileCardCover 图片内一处，不影响滚动）。

**验收**：详情页四个 Tab 均可上下滚动、长列表可滑到底。

### BUG 0.3 角色卡打开后读取不到世界书数据

**根因**：`CardDetailView.wbEntries` 与 `WorldbookView.openFileWb` 只认 `extensions.world_book.entries` 字典形态，未用桌面版 `extractBookEntries`（`js/utils/cardLoader.js`），三种形态失败：顶层 `character_book`（老 V1）、`entries` 数组、脏结构。

**修复**：两处统一改用 `extractBookEntries`（已导出纯函数，永不抛错）：
```js
import { extractBookEntries } from '../../utils/cardLoader.js';
// CardDetailView：const book = d.extensions?.world_book ?? d.character_book ?? null;
// 返回数组形态，模板 v-for=(e,i)，增删走数组 API，保存同步写回原容器。
// WorldbookView：entries: extractBookEntries(wb.wb)；saveAll 保持 wrapped 结构。
```
与阶段 5「词条增强编辑」联动。

**验收**：V1 卡/数组卡/字典卡三种形态世界书均正确显示与增删改。

### BUG 0.4 世界书功能界面与桌面版不符

**根因**：`WorldbookView.vue` 顶部混入「卡内世界书」区块（`cardWithWb`）；页面名「世界书」未对齐桌面「世界书库」形态；无任何导入能力；桥接 `scanTargetFolder` 只支持 `.png`。

**修复**：
1. 删除「卡内世界书」区块（卡内世界书只在角色卡详情页编辑）
2. `MobileApp.vue` Tab 文案「世界书」→「世界书库」（与角色卡库同级）
3. 扩展 `LibraryFsPlugin.scanFolder` 支持 `ext:'.json'` → 新增 `api.importWorldbooksFromFolder()`：扫描目录世界书 JSON（含 `entries` 特征，复用 `extractBookEntries` 判定）→ `createWorldbook` 入库
4. 世界书库工具栏：文件夹扫描导入 / JSONL 批量导入（`<input type="file" accept=".jsonl">` → `createWorldbook` 逐个入库）/ 直链导入（`api.fetchWbUrl`）/ 批量导出（`exportWorldbooksBatch`）/ 查重（保留）

（对应阶段 5「世界书导入导出全集」，此处先完成改名与结构对齐。）

**验收**：世界书库只显示独立世界书；三种导入方式可用；Tab 显示「世界书库」。

### BUG 0.5 角色卡打开后很多条目不能折叠

**根因**：世界书/正则条目（`.wb-item`/`.regex-item`）全部平铺展开，无折叠交互。

**修复**：条目卡改可折叠面板——头行（开关+名称+删除+箭头）常驻，点击头行展开/收起正文；正则条目默认只显示名称，正文（findRegex/replaceString）点击展开；「高级设定」折叠块保留。

**验收**：条目多时默认紧凑，逐条展开收起，保存互不影响。

### BUG 0.6 设置界面出现乱码

**根因（已排除项+最可能项）**：源文件/`index.html` 编码均正常。最可能：Vant 图标字体未被 Vite 打进 `web/`（`van-icon` 显示占位方块，设置页图标最密集）、或 `✓`/`·`/`…` 特殊字符在部分安卓 WebView 字体下渲染为方块、或 0.1 未修时的观感叠加。

**修复**：
1. `.mobile-shell { font-family: -apple-system, "PingFang SC", "HarmonyOS Sans SC", "Noto Sans SC", "Microsoft YaHei", sans-serif; }`
2. 设置页 `✓`/`·`/`…` 改常规文本（`已授权`/`-`/`...`）或指定 fallback 字体
3. 检查 `web/assets` 是否含 vant 字体；若无在 `vite.config.mjs` 调整 assets 内联规则
4. 真机截图确认位置，渲染产物 chunk 与源码对照

**验收**：设置页文字/图标无方块无乱码，浅深主题均可读。

### BUG 0.7 聊天界面渲染功能缺失、文字对比不明显

**根因**：测卡为纯文本气泡（`<pre class="b-content">`）；`.bubble.user` 青色白字、`.bubble.assistant` 白底灰字，深浅主题下区分度低。

**修复**：
1. 测卡工具栏加「渲染」开关：AI 气泡 `v-html` + DOMPurify 清洗（依赖已含 dompurify）
2. 对比度增强：用户气泡主色+纯白粗体、字号 `15px` 行高 `1.7`；AI 气泡主题化背景+边框；姓名行改彩色小徽标（「我 / 角色名」区分）；输入框文字接入主题变量
3. 渲染失败回退纯文本

（对应阶段 4「聊天渲染模式」。）

**验收**：渲染开关下 HTML/表格/图片按渲染展示且无 XSS；深浅主题气泡边界清晰。

### 1.1 卡片删除真正进入回收站

- 验收：删除后文件在库根 `.trash/`，列表不受影响

### 1.2 WebP 卡片编辑友好降级
- 修复：`CardDetailView.save()` 捕获 WebP 错误时提示「暂不支持原地编辑，建议桌面端转 PNG」
- 验收：WebP 卡保存给明确提示
