# 移动版（Android APP）功能补全方案

> 基于桌面版 v1.9.0 功能面逐项对比移动版得出，按实施优先级依次落地。
> 依据：桥接层 `js/bridge/android.js`（方法均已核心实现）与移动端 UI（`js/mobile/`）现状。
> 说明：任何表格中「桥接已就绪」表示 `api.xxx` 已可用，只需补 UI。

---

## P0 — 数据安全修复（最优先）

### 1. 卡片删除真正进入回收站
- 现状：`CardLibraryView.vue` 删除走 `removeCard → deleteFile`（物理删除），弹窗文案却写「移入系统回收站」。
- 改动：`useMobileLibrary.js` 的 `removeCard` 改调 `api.trashFiles([path])`（桥接已实现，移入库根 `.trash`）；文案同步改为「将移入回收站」。
- 验收：删除后文件出现在库根 `.trash/`，列表不受影响（scan 跳过点开头目录）。

### 2. WebP 卡片编辑友好降级
- 现状：`saveCard` 遇 WebP 直接失败（android.js `_saveCardWebp`）。
- 改动：`CardDetailView.vue` 的 `save()` 捕获该错误时提示「WebP 卡暂不支持原地编辑，建议桌面端转换为 PNG 后使用」。
- 验收：编辑 WebP 卡保存给出明确提示而非报错。

## P1 — 桥接已就绪，只补 UI 入口

### 3. 卡片快照（详情页）
- 入口：`CardDetailView.vue` 导航栏右侧加 📸 → 快照弹窗（新建/列表/恢复/删除）。
- 桥接：`createManualSnapshot(path)`、`listCardSnapshots(path)`（返回 `[{fileName,path,mtimeMs,size,isManual}]`）、`restoreCardSnapshot({filePath,snapshotPath})`、`deleteCardSnapshot(snapshotPath)`。
- 通用组件：新建 `js/mobile/components/SnapshotModal.vue`（方案 3/4 共用）。

### 4. 世界书快照（世界书编辑器）
- 入口：`WorldbookView.vue` 编辑器导航栏加快照图标，复用 SnapshotModal。
- 桥接：`listWorldbookSnapshots(path)` / `restoreWorldbookSnapshot({filePath,snapshotPath})` / `deleteWorldbookSnapshot(snapshotPath)`。

### 5. 换卡图
- 入口：`CardDetailView.vue` 设定 Tab 封面区加「换图」。
- 选图：WebView `<input type="file" accept="image/*">` → `FileReader` 读 base64 → `api.replaceCardImage({filePath, imageBase64, imageType})`（无需新原生方法）。
- 验收：换图后封面更新、JSON 无损。

### 6. 复制副本
- 入口：卡片库长按动作单 / 详情页菜单加「复制副本」。
- 桥接：`duplicateFile(path)` → 返回 `{newPath}`，`load()` 刷新可见 `_copy_时间戳` 副本。

### 7. 打开文件位置 / 打开文件
- 入口：`CardDetailView.vue` 设定 Tab 顶部「在文件管理器显示」「打开文件」。
- 桥接：`api.showItemInFolder(path)`、`api.openPath(path)`。

### 8. 查看回收站（.trash）
- 入口：`SettingsView.vue`「功能」组加「回收站」→ 新页面 `TrashView.vue`。
- 能力：复用 `api.scan` 列目录；恢复 = `LibraryFs.move` 移回原相对路径；清空 = `LibraryFs.delete(recursive)`；`api.openGlobalTrash()` 兜底打开文件夹。

### 9. URL 导入（角色卡下载 + 世界书拉取）
- 入口：卡片库顶部加「URL 导入」弹窗；世界书库加「URL 直链导入」。
- 桥接：`downloadCardFromUrl({url, destFolder})`（自动解析 PNG/JSON 命名）、`fetchWbUrl(url)`（返回 JSON 文本后经 `createWorldbook` 入库）。

### 10. 模型列表拉取（测卡 API 弹窗）
- 入口：`CardDetailView.vue` 测卡 API 弹窗模型字段加「拉取模型」。
- 桥接：`fetchModels(endpoint, apiKey, apiType)` → OpenAI 取 `data.data[].id`，Anthropic 取 `data.data[].id`。

### 11. 批量导出世界书
- 入口：世界书库顶部「批量导出」→ 分享 ZIP。
- 桥接：`exportWorldbooksBatch(paths)` → 复用批量 ZIP 分享链路（同卡片批量导出）。

### 12. 物理推送酒馆 + 自动检测
- 入口：`CardDetailView.vue` 推送弹窗增加「物理复制到目标文件夹」模式。
- 桥接：`selectPushFolder()` 选目录 → `pushToCustomDir({filePaths, targetDir})`；`autoDetectTavernPath()` 回显已存路径。

## P2 — 管理增强（中等投入）

### 13. 批量多选操作
- 改造：卡片库加「管理模式」开关 → 卡片勾选（复用磁盘扫描 checkbox 模式）→ 底部操作条：移分组 / 删除(trash) / 导出 ZIP。
- 复用：`trashFiles(paths)`、`exportBatchPackage(paths)`、`moveCardToGroup` 循环。

### 14. 分组管理补充
- 入口：分组横滚条末尾「＋ 管理分组」：新建 / 重命名 / 删除空分组。
- 桥接：`renameGroupFolder`、`deleteEmptyGroupFolder`。

### 15. 排序选择 + Token 徽标 + 列表紧凑模式
- 排序：最新 / 名称 / Token 三选（本地记忆）；列表模式显示每卡 Token 徽标（复用 `estimateTokens`）；增加高密度列表开关。

### 16. 标签系统增强
- 详情页标签区升级为标签面板：预设标签池点选（数据固化为移动端 JSON）、收藏标签、中英显示切换。

### 17. 超级搜索增强（全字段 + 语法）
- `CardLibraryView.vue` 的过滤逻辑改复用桌面 `extractCardSearchableText`（`js/composables/useSearch.js` 已导出纯函数）做全字段匹配；支持 `tag:`/`author:` 前缀与 `-排除`；搜索框长按弹出「带世界书 / 带正则」快捷 chip。

### 18. 详情页大图预览
- `MobileCardCover.vue` 增加点击 → 全屏 `van-popup` 预览原图。

## P3 — AI 系重资产（分阶段）

### 19. AI 智能打标（移动精简版）
- 入口：详情页导航栏 🤖 → 单卡模式：自定义提示词 + 候选标签池 + 一键打标（复用测卡 API 配置与 `sendChatMessage`，保留重试）。
- 验收：返回标签写入 cards.tags 并保存。

### 20. AI 工具（一键汉化 / 格式升维）
- 入口：详情页设定 Tab 底部两按钮，逐字段走 `sendChatMessage` 翻译/重构，写入后提示保存。

### 21. 关系图谱（移动适配）
- 新页 `GraphView.vue`：引入桌面已依赖的 ECharts，数据构造复用 `useGraph.js` 纯函数，力导布局 + 分组着色 + 点节点跳详情。

### 22. 全库词条搜索
- 新弹窗：遍历库与世界书用 `extractBookEntries` 建索引，按触发词/正文搜索，点结果跳卡片详情并定位世界书 Tab。

### 23. 全局资产中心
- 新页聚合两 Tab：全部内嵌世界书词条 / 全部正则脚本，可编辑并回写原卡。

### 24. 状态栏模板库
- 详情页状态栏预览区增加模板库弹窗：内置 15 套渲染模板 + 指令模板（从 `useStatusbarPreview.js` 抽取共享常量），点选注入卡片正则；增加脚本勾选隔离。

### 25. 聊天渲染模式
- 测卡 Tab 增加「渲染」开关（气泡 `v-html` + DOMPurify 清洗，桌面 `renderHTML` 移入共享工具）；API 弹窗加系统提示词预设下拉。

## 建议执行顺序

```
P0 数据安全(1-2) → P1 补门(3-12，复用组件批量推进)
→ P2 管理增强(13-18) → P3 AI 系(19-25) → P4 世界书 IDE(26-27)
```

每完成一组执行 `npm run build:android` 出包，真机重点回归：SAF 授权、长按菜单、滚动、ZIP 分享、鸿蒙 7 卓易通兼容。
