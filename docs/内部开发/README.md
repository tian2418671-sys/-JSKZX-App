## 📁 目录结构

```
docs/
├── 内部开发/          ← 开发团队专用
│   ├── BUG修复/       ← BUG 定位、修复日志
│   ├── 实测记录/      ← 功能实测、回归测试报告
│   ├── 技术文档/      ← 核心代码解析、经验总结
│   ├── 方案设计/      ← 新功能方案、评审稿
│   ├── 截图记录/      ← 实测截图（按日期）
│   └── 脚本工具/      ← 辅助脚本
├── 用户更新/          ← 用户可见的更新日志
│   ├── 2026-09/
│   └── 2026-08/
└── 铁律/             ← 开发流程规范
```
