## 二、发现并修复的问题

### 1. 全应用滚动失效（真机专属）✅
- 现象：真机（WebView 101）全部页面无法触摸滚动；模拟器（新内核）不复现
- 根因：`css/style.css` body `overflow:hidden`——body 的 overflow 会传播到视口，旧内核严格执行锁死滚动手势；程序化 scrollTo 仍生效所以肉眼难察觉
- 修复：`overflow: visible`；实测扫描中列表 480.5→968.5 连续位移、设置页滑到底正常

### 2. 世界书条目增删 UI 不刷新 ✅
- 现象：卡内世界书"添加条目"点击后界面纹丝不动（实际数据已加），切页签才突然出现
- 根因：`getCardEmbeddedWb` 新建书分支返回**裸对象**（非响应式代理）→ 增删不触发渲染
- 修复：始终从 `d.character_book` 读回响应式对象；实证修复后点击即时 +1（1→2→3）、删除即时 -1

### 3. 保存后世界书格式脏（存量缺陷）✅
- 现象：编辑世界书保存后，磁盘 entries 变字典（`wb_0` 键）+ `_keysText`/`_secKeysText` 临时字段残留，影响外部工具兼容
- 根因：doSave 在"字段剥离/字典→数组"与写盘之间存在 await（快照策略），期间 Vue 微任务重渲染让 wbEntries computed 把数组转回字典并回填临时字段
- 修复：`saveCardData` / `renameCardTo` / `WorldbookView.saveAll` 三路写盘前，对**深拷贝副本**执行 `normalizeCardEmbeddedWbPayload`（与响应式时序无关）；实测保存后磁盘为数组形态、无临时字段

### 4. 万卡库崩溃（OOM）✅
- 详见 [BUG修复/2026-09-19_BUG-18_万卡库崩溃(OOM)修复.md](../BUG修复/2026-09-19_BUG-18_万卡库崩溃(OOM)修复.md)
- 修复后：syncCards 分 32 批 3.5 秒完成、零 OOM、堆峰值 ~40MB

### 5. 视图切换按钮图标偏移 ✅
- 现象：卡片库"平铺/网格/海报/翻页"4 按钮选中态图标不居中
- 根因：`.view-bar .van-icon { margin-left:12px }` 泛匹配（原意给排序区间距，但排序箭头为伪元素、无实际受益）→ 28px 按钮内图标偏右 12px（实测左 13/右 1）
- 修复：删除该规则；实测 4 按钮全部 7/7 居中（offset=0）

## 五、遗留（已知未修）
