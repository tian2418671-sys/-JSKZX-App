## 1. 背景与问题建模

在 Android 端（尤其是 ColorOS、HyperOS/MIUI、OriginOS 等深度定制 ROM）的实机运行中，本地文件读取能力在 **SAF（Storage Access Framework）四段能力链** 上存在多处断裂，且部分魔改系统存在 DocumentsUI 组件残废的问题：

| 阶段 | 现状缺陷 | 用户侧表现 |
| :--- | :--- | :--- |
| **① 定位（Initial URI）** | `putInitialDownloadsUri()` 传入了 `MediaStore.Downloads.EXTERNAL_CONTENT_URI`，与 SAF Tree/Document 选择器期望的 `com.android.externalstorage.documents` 域不匹配。 | 打开系统文件选择器时无法自动定位到 `Download` 目录，停留在最近文件或空白根页。 |
| **② 授权持久化（Persist）** | `takePersistableUriPermission()` 硬编码请求 `READ \| WRITE` 且直接吞掉异常；未过滤系统实际授予的 `Intent.getFlags()`。 | 在只读挂载点或部分三方选择器上抛出 `SecurityException`，导致重启 App 后授权丢失。 |
| **③ 枚举（Query & Loading）** | 1. 直接查询或使用 `DocumentFile.listFiles()`，未处理 Provider 异步加载时的 `DocumentsContract.EXTRA_LOADING` 状态。<br>2. `scanFolderResult()` 在主线程同步递归遍历目录树，且使用 `DocumentFile.listFiles()` 触发海量独立 IPC。 | 大目录或冷启动首次枚举时返回空列表或残缺列表；导入文件夹时 UI 严重卡死甚至触发 ANR。 |
| **④ 兜底能力缺失** | 仅依赖 SAF 单一后端。当定制 ROM 禁用/魔改 DocumentsUI 导致无法选目录时，缺乏基于路径（`File` API）的兜底机制。 | 部分机型彻底无法选择或读取本地角色卡/世界书目录。 |

### 修复策略：P0 + P1 双轨并进
- **P0（修复 SAF 四段能力链）**：在保留现有 SAF 架构的基础上，修正初始定位 URI、按掩码安全持久化权限、增加 `EXTRA_LOADING` 异步等待机制、全面废除 `DocumentFile.listFiles()` 并改为子线程 `Cursor` 批量枚举。
- **P1（引入路径级全盘后端 `MANAGE_EXTERNAL_STORAGE`）**：提供“全盘访问模式 + 应用内目录浏览器”作为并列/兜底后端，彻底绕开残废的系统 DocumentsUI，并与 SAF 后端实现**双向状态互斥与无缝切换**。

## 2. P0：SAF 四段能力链修复方案

### 2.1 【定位】修正 `putInitialDownloadsUri`（移除未授权查询）

> **⚠️ 评审修正说明**：在用户尚未通过 SAF 授权前，App 对 `com.android.externalstorage.documents` 下的 URI 没有读取权限，直接调用 `ContentResolver.query()` 会必抛 `SecurityException`。因此改为通过 `PackageManager.resolveContentProvider()` 校验系统是否存在外部存储 DocumentsProvider。

**修改位置**：`LibraryFsPlugin.java`

```java
private static final String EXT_STORAGE_AUTHORITY = "com.android.externalstorage.documents";
private static final String DOWNLOAD_DOC_ID = "primary:Download";

private boolean hasExternalStorageDocumentsProvider() {
    try {
        Context ctx = getContext();
        if (ctx == null) return false;
        PackageManager pm = ctx.getPackageManager();
        return pm != null && pm.resolveContentProvider(EXT_STORAGE_AUTHORITY, 0) != null;
    } catch (Exception ignored) {
        return false;
    }
}

private void putInitialDownloadsUri(Intent intent) {
    if (Build.VERSION.SDK_INT < Build.VERSION_CODES.O) return;
    try {
        if (hasExternalStorageDocumentsProvider()) {
            Uri initialUri = DocumentsContract.buildDocumentUri(EXT_STORAGE_AUTHORITY, DOWNLOAD_DOC_ID);
            intent.putExtra(DocumentsContract.EXTRA_INITIAL_URI, initialUri);
        }
    } catch (Exception ignored) {}
}
```

### 2.2 【授权持久化】按实际授予掩码持久化 & 双向状态互斥

> **⚠️ 评审修正说明**：当用户通过 SAF 成功设置目录（`setRootUri`）时，必须同步移除 `KEY_ROOT_PATH`，防止因路径后端优先级更高而导致用户无法从“全盘路径模式”切回“SAF 模式”。

**修改位置**：`LibraryFsPlugin.java`

```java
private static final String KEY_ROOT_URI = "root_uri";
private static final String KEY_ROOT_PATH = "root_path"; // P1 新增，与 KEY_ROOT_URI 互斥

private static class PersistResult {
    final boolean persisted;
    final int persistedFlags;
    final String error;

    PersistResult(boolean persisted, int persistedFlags, String error) {
        this.persisted = persisted;
        this.persistedFlags = persistedFlags;
        this.error = error;
    }
}

private PersistResult tryPersist(Intent data, Uri uri) {
    if (uri == null) return new PersistResult(false, 0, "uri is null");
    int rawFlags = (data != null) ? data.getFlags() : 0;
    if ((rawFlags & Intent.FLAG_GRANT_PERSISTABLE_URI_PERMISSION) == 0) {
        return new PersistResult(false, 0, "Provider did not grant persistable permission flag");
    }
    int modeFlags = rawFlags & (Intent.FLAG_GRANT_READ_URI_PERMISSION | Intent.FLAG_GRANT_WRITE_URI_PERMISSION);
    if (modeFlags == 0) {
        modeFlags = Intent.FLAG_GRANT_READ_URI_PERMISSION;
    }
    try {
        getContext().getContentResolver().takePersistableUriPermission(uri, modeFlags);
        return new PersistResult(true, modeFlags, null);
    } catch (SecurityException se) {
        // 降级尝试仅申请只读持久化
        if ((modeFlags & Intent.FLAG_GRANT_WRITE_URI_PERMISSION) != 0) {
            try {
                int readOnly = Intent.FLAG_GRANT_READ_URI_PERMISSION;
                getContext().getContentResolver().takePersistableUriPermission(uri, readOnly);
                return new PersistResult(true, readOnly, null);
            } catch (Exception e2) {
                return new PersistResult(false, 0, e2.getMessage());
            }
        }
        return new PersistResult(false, 0, se.getMessage());
    } catch (Exception e) {
        return new PersistResult(false, 0, e.getMessage());
    }
}

private void setRootUri(Uri uri) {
    SharedPreferences.Editor editor = prefs().edit();
    if (uri == null) {
        editor.remove(KEY_ROOT_URI);
    } else {
        editor.putString(KEY_ROOT_URI, uri.toString());
        // 关键：切换回 SAF 模式时清除路径模式配置，保证双后端严格互斥
        editor.remove(KEY_ROOT_PATH);
    }
    editor.apply();
}
```

在 `pickFolderResult` 中回传诊断字段（且统一使用 `resolve` 携带 `cancelled/error` 字段或与前端 `try/catch` 保持一致）：

```java
@ActivityCallback
private void pickFolderResult(PluginCall call, ActivityResult result) {
    if (call == null) return;
    Intent data = result.getData();
    if (result.getResultCode() != Activity.RESULT_OK || data == null || data.getData() == null) {
        call.reject("用户取消选择");
        return;
    }
    Uri treeUri = data.getData();
    PersistResult pr = tryPersist(data, treeUri);
    setRootUri(treeUri);
    clearRelIndex();

    DocumentFile doc = DocumentFile.fromTreeUri(getContext(), treeUri);
    String name = (doc != null && doc.getName() != null) ? doc.getName() : treeUri.getLastPathSegment();

    JSObject ret = new JSObject();
    ret.put("backend", "saf");
    ret.put("uri", treeUri.toString());
    ret.put("name", name != null ? name : "根目录");
    ret.put("persisted", pr.persisted);
    ret.put("persistedFlags", pr.persistedFlags);
    if (pr.error != null) ret.put("persistWarning", pr.error);
    call.resolve(ret);
}
```

### 2.3 【枚举】引入 `queryChildrenSettled` 处理 `EXTRA_LOADING`

当 DocumentsProvider 仍在后台构建目录列表时，返回的 `Cursor.getExtras()` 中 `DocumentsContract.EXTRA_LOADING` 为 `true`。此时需注册 `ContentObserver` 等待加载完成信号后再重新查询。

**修改位置**：`LibraryFsPlugin.java`

```java
private static final String[] DOC_CHILD_PROJECTION = new String[]{
    DocumentsContract.Document.COLUMN_DOCUMENT_ID,
    DocumentsContract.Document.COLUMN_DISPLAY_NAME,
    DocumentsContract.Document.COLUMN_MIME_TYPE,
    DocumentsContract.Document.COLUMN_SIZE,
    DocumentsContract.Document.COLUMN_LAST_MODIFIED
};

private Cursor queryChildrenSettled(ContentResolver cr, Uri childrenUri, String[] projection, long timeoutMs) {
    Cursor c = cr.query(childrenUri, projection, null, null, null);
    if (c == null) return null;

    Bundle extras = c.getExtras();
    boolean isLoading = extras != null && extras.getBoolean(DocumentsContract.EXTRA_LOADING, false);
    if (!isLoading) {
        return c;
    }

    final CountDownLatch latch = new CountDownLatch(1);
    ContentObserver observer = new ContentObserver(new Handler(Looper.getMainLooper())) {
        @Override
        public void onChange(boolean selfChange) {
            latch.countDown();
        }
    };

    try {
        c.registerContentObserver(observer);
        // 注册后立即复查一次，减小竞态窗口
        Bundle recheck = c.getExtras();
        if (recheck == null || !recheck.getBoolean(DocumentsContract.EXTRA_LOADING, false)) {
            latch.countDown();
        }
        latch.await(timeoutMs, TimeUnit.MILLISECONDS);
    } catch (InterruptedException ignored) {
        Thread.currentThread().interrupt();
    } finally {
        try { c.unregisterContentObserver(observer); } catch (Exception ignored) {}
        try { c.close(); } catch (Exception ignored) {}
    }

    return cr.query(childrenUri, projection, null, null, null);
}
```

- **全面替换 `DocumentFile.listFiles()`**：
  在 `buildRelIndex()`、`scanWbTree()` 以及 `scanFolderResult()` 中，统一废弃 `DocumentFile.listFiles()`，改用 `DocumentsContract.buildChildDocumentsUriUsingTree(treeUri, parentDocId)` + `queryChildrenSettled(cr, childrenUri, DOC_CHILD_PROJECTION, 1500)` 遍历，直接从 `Cursor` 读取文件名、MIME 类型、大小和修改时间，通过 `DocumentsContract.buildDocumentUriUsingTree(treeUri, childDocId)` 构造子项 URI。

```java
@PluginMethod
public void scanFolder(PluginCall call) {
    try {
        Intent intent = new Intent(Intent.ACTION_OPEN_DOCUMENT_TREE);
        intent.addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION
                | Intent.FLAG_GRANT_PERSISTABLE_URI_PERMISSION
                | Intent.FLAG_Grant_PREFIX_URI_PERMISSION);
        putInitialDownloadsUri(intent);
        startActivityForResult(call, intent, "scanFolderResult");
    } catch (Exception e) {
        call.reject("无法启动系统目录选择器: " + e.getMessage());
    }
}

@ActivityCallback
private void scanFolderResult(PluginCall call, ActivityResult result) {
    if (call == null) return;
    Intent data = result.getData();
    if (result.getResultCode() != Activity.RESULT_OK || data == null || data.getData() == null) {
        call.reject("用户取消选择");
        return;
    }
    final Uri treeUri = data.getData();
    tryPersist(data, treeUri);

    final String extFilter = call.getString("ext", "");
    final Context appCtx = getContext().getApplicationContext();

    SCAN_EXEC.execute(() -> {
        try {
            JSArray files = new JSArray();
            String rootDocId = DocumentsContract.getTreeDocumentId(treeUri);
            scanTreeCursorRecursive(appCtx.getContentResolver(), treeUri, rootDocId, "", extFilter, files);

            JSObject ret = new JSObject();
            ret.put("uri", treeUri.toString());
            ret.put("files", files);
            call.resolve(ret);
        } catch (Exception e) {
            call.reject("扫描文件夹失败: " + e.getMessage());
        }
    });
}
```

### 3.2 原生插件接口设计（含兜底跳转、生命周期回调与多存储卷支持）

> **⚠️ 评审修正说明**：
> 1. `requestAllFilesAccess` 改用 `startActivityForResult`，在用户从系统设置页返回 App 时复查 `Environment.isExternalStorageManager()`，返回真实的授权结果。
> 2. 增加无 `package:` URI 的 `ACTION_MANAGE_ALL_FILES_ACCESS_PERMISSION` 兜底，防止定制 ROM 抛出 `ActivityNotFoundException`。
> 3. 在 `allFilesAccessState` 中通过 `StorageManager` 返回所有已挂载存储卷（内部存储、SD 卡、OTG U 盘）的根路径列表，解决 `/storage` 父目录不可读导致无法切换到外置 SD 卡的问题。

**修改位置**：`LibraryFsPlugin.java`

```java
private boolean hasAllFilesAccessPermission() {
    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.R) {
        return Environment.isExternalStorageManager();
    } else {
        return ContextCompat.checkSelfPermission(getContext(), Manifest.permission.READ_EXTERNAL_STORAGE)
                == PackageManager.PERMISSION_GRANTED;
    }
}

private JSArray getMountedVolumeRoots() {
    JSArray roots = new JSArray();
    try {
        File primary = Environment.getExternalStorageDirectory();
        if (primary != null) {
            JSObject item = new JSObject();
            item.put("name", "内部共享存储");
            item.put("path", primary.getAbsolutePath());
            item.put("primary", true);
            roots.put(item);
        }
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.N) {
            StorageManager sm = (StorageManager) getContext().getSystemService(Context.STORAGE_SERVICE);
            if (sm != null && Build.VERSION.SDK_INT >= Build.VERSION_CODES.R) {
                for (StorageVolume vol : sm.getStorageVolumes()) {
                    File dir = vol.getDirectory();
                    if (dir != null && (primary == null || !dir.getAbsolutePath().equals(primary.getAbsolutePath()))) {
                        JSObject vObj = new JSObject();
                        vObj.put("name", vol.getDescription(getContext()));
                        vObj.put("path", dir.getAbsolutePath());
                        vObj.put("primary", vol.isPrimary());
                        roots.put(vObj);
                    }
                }
            }
        }
    } catch (Exception ignored) {}
    return roots;
}

@PluginMethod
public void allFilesAccessState(PluginCall call) {
    JSObject ret = new JSObject();
    ret.put("sdkInt", Build.VERSION.SDK_INT);
    ret.put("granted", hasAllFilesAccessPermission());
    ret.put("defaultRoot", Environment.getExternalStorageDirectory().getAbsolutePath());
    ret.put("volumes", getMountedVolumeRoots());
    call.resolve(ret);
}

@PluginMethod
public void requestAllFilesAccess(PluginCall call) {
    if (Build.VERSION.SDK_INT < Build.VERSION_CODES.R) {
        JSObject ret = new JSObject();
        ret.put("granted", hasAllFilesAccessPermission());
        call.resolve(ret);
        return;
    }
    if (Environment.isExternalStorageManager()) {
        JSObject ret = new JSObject();
        ret.put("granted", true);
        call.resolve(ret);
        return;
    }
    try {
        Intent intent = new Intent(Settings.ACTION_MANAGE_APP_ALL_FILES_ACCESS_PERMISSION);
        intent.setData(Uri.parse("package:" + getContext().getPackageName()));
        startActivityForResult(call, intent, "allFilesAccessResult");
    } catch (Exception e1) {
        try {
            // 定制 ROM 兜底：跳转到全局“所有文件访问权限”列表页
            Intent fallback = new Intent(Settings.ACTION_MANAGE_ALL_FILES_ACCESS_PERMISSION);
            startActivityForResult(call, fallback, "allFilesAccessResult");
        } catch (Exception e2) {
            call.reject("当前系统不支持跳转全盘访问授权页: " + e2.getMessage());
        }
    }
}

@ActivityCallback
private void allFilesAccessResult(PluginCall call, ActivityResult result) {
    if (call == null) return;
    JSObject ret = new JSObject();
    ret.put("granted", hasAllFilesAccessPermission());
    ret.put("volumes", getMountedVolumeRoots());
    call.resolve(ret);
}

@PluginMethod
public void listDirByPath(PluginCall call) {
    if (!hasAllFilesAccessPermission()) {
        call.reject("未授予所有文件访问权限");
        return;
    }
    String rawPath = call.getString("path", "");
    if (rawPath == null || rawPath.trim().isEmpty()) {
        rawPath = Environment.getExternalStorageDirectory().getAbsolutePath();
    }
    final String targetPath = rawPath;
    SCAN_EXEC.execute(() -> {
        try {
            File dir = new File(targetPath).getCanonicalFile();
            if (!dir.exists() || !dir.isDirectory()) {
                call.reject("目录不存在或不可访问: " + targetPath);
                return;
            }
            File[] children = dir.listFiles();
            if (children == null) {
                call.reject("无法枚举该目录（权限受限）: " + dir.getAbsolutePath());
                return;
            }
            // 按“目录优先 + 名称字典序”排序
            Arrays.sort(children, (a, b) -> {
                if (a.isDirectory() != b.isDirectory()) {
                    return a.isDirectory() ? -1 : 1;
                }
                return a.getName().compareToIgnoreCase(b.getName());
            });

            JSArray entries = new JSArray();
            for (File f : children) {
                String name = f.getName();
                if (name.startsWith(".")) continue; // 默认跳过隐藏文件
                JSObject item = new JSObject();
                item.put("name", name);
                item.put("path", f.getAbsolutePath());
                item.put("isDir", f.isDirectory());
                item.put("size", f.isFile() ? f.length() : 0);
                item.put("mtime", f.lastModified());
                entries.put(item);
            }

            File parent = dir.getParentFile();
            String parentPath = (parent != null && parent.canRead()) ? parent.getAbsolutePath() : null;

            JSObject ret = new JSObject();
            ret.put("path", dir.getAbsolutePath());
            ret.put("parent", parentPath);
            ret.put("entries", entries);
            call.resolve(ret);
        } catch (Exception e) {
            call.reject("读取目录失败: " + e.getMessage());
        }
    });
}

@PluginMethod
public void setLibraryRootPath(PluginCall call) {
    if (!hasAllFilesAccessPermission()) {
        call.reject("未授予所有文件访问权限");
        return;
    }
    String rawPath = call.getString("path", "");
    if (rawPath == null || rawPath.trim().isEmpty()) {
        call.reject("路径不能为空");
        return;
    }
    try {
        File dir = new File(rawPath).getCanonicalFile();
        if (!dir.exists() || !dir.isDirectory() || !dir.canRead()) {
            call.reject("所选路径无效或不可读");
            return;
        }
        // 保存路径后端，并清除 SAF URI 保持严格互斥
        prefs().edit()
               .putString(KEY_ROOT_PATH, dir.getAbsolutePath())
               .remove(KEY_ROOT_URI)
               .apply();
        clearRelIndex();

        JSObject ret = new JSObject();
        ret.put("backend", "path");
        ret.put("path", dir.getAbsolutePath());
        ret.put("name", dir.getName().isEmpty() ? dir.getAbsolutePath() : dir.getName());
        call.resolve(ret);
    } catch (Exception e) {
        call.reject("设置路径失败: " + e.getMessage());
    }
}
```

### 3.3 双后端全链路统一分流改造清单（P1-3）

为了避免在十余个 `@PluginMethod` 中散落重复的分支代码，在 `LibraryFsPlugin.java` 中增加统一的后端判定与相对路径解析辅助层：

```java
private boolean isPathBackend() {
    String path = prefs().getString(KEY_ROOT_PATH, null);
    return path != null && !path.isEmpty();
}

private File getRootDirFile() {
    String path = prefs().getString(KEY_ROOT_PATH, null);
    return (path != null && !path.isEmpty()) ? new File(path) : null;
}
```

**需同步适配 `isPathBackend()` 分支的方法清单**：

| 功能模块 | 涉及方法 | `path` 后端实现方式 | `saf` 后端实现方式 |
| :--- | :--- | :--- | :--- |
| **库状态查询** | `libraryInfo` | 检查 `getRootDirFile().canRead()`，返回 `backend: "path"` | 检查 `DocumentFile.fromTreeUri().canRead()`，返回 `backend: "saf"` |
| **索引与扫描** | `buildRelIndex` / `scanStart` | 递归遍历 `File.listFiles()`，记录相对路径与 `File` 映射 | `queryChildrenSettled()` 递归遍历 `Cursor`，记录相对路径与 `DocumentUri` |
| **世界书扫描** | `scanWbTree` | 基于 `new File(rootDir, wbSubPath)` 遍历 `.json` | 基于 `queryChildrenSettled()` 遍历子目录 |
| **文件读取** | `readFile` / `readBuffer` / `fileByRelPath` | `new FileInputStream(new File(rootDir, relPath))` | `ContentResolver.openInputStream(docUri)` |
| **文件写入/修改** | `writeFile` / `saveCard` / `deleteFile` / `renameFile` / `mkdir` | 标准 `FileOutputStream`、`File.delete()`、`File.renameTo()`、`File.mkdirs()` | `DocumentsContract.createDocument()`、`deleteDocument()`、`renameDocument()` |

## 4. 渲染层（Web 端）接线与交互降级方案

### 4.1 统一错误捕获与降级弹窗

> **⚠️ 评审修正说明**：Capacitor 原生侧调用 `call.reject(...)` 时，JS 侧 `await LibraryFs.xxx()` 会抛出 Promise 异常。因此在 `js/bridge/android.js` 中必须使用 `try { ... } catch (err) { ... }` 捕获异常，区分“用户主动取消”与“系统选择器故障”，并在故障或用户主动切换时唤起内置目录浏览器。

**修改位置**：`js/bridge/android.js`

```javascript
async function selectFolder(options = {}) {
  const forcePathMode = options.forcePathMode === true;

  if (!forcePathMode) {
    try {
      const res = await LibraryFs.pickFolder();
      if (res && (res.uri || res.path)) {
        if (res.persistWarning) {
          console.warn('[LibraryFs] 权限持久化警告:', res.persistWarning);
        }
        return res;
      }
    } catch (err) {
      const msg = (err && err.message) ? err.message : String(err);
      // 用户主动取消时，提供显式入口切换到“全盘路径模式”（应对系统选择器进不去目标目录的情况）
      const wantFallback = window.confirm(
        `系统目录选择器未能完成选择（${msg}）。\n\n如果您的手机系统文件管理器无法显示 Download 目录或无法点击“使用此文件夹”，是否切换为【全盘路径浏览模式】？`
      );
      if (!wantFallback) {
        return { cancelled: true, error: msg };
      }
    }
  }

  // 进入 P1 全盘访问 + 应用内目录浏览器流程
  return await openInAppDirectoryPicker();
}

async function openInAppDirectoryPicker() {
  let state = await LibraryFs.allFilesAccessState();
  if (!state.granted) {
    const confirmed = window.confirm(
      '使用内置目录浏览器需要授予“所有文件访问权限”。\n点击确定将跳转至系统设置页，开启开关后返回应用即可。'
    );
    if (!confirmed) return { cancelled: true };
    state = await LibraryFs.requestAllFilesAccess();
    if (!state || !state.granted) {
      alert('未检测到“所有文件访问权限”，无法使用内置目录浏览器。');
      return { cancelled: true, error: 'permission_denied' };
    }
  }

  // 打开前端内置目录选择 Modal，支持顶部切换 state.volumes（内部存储 / SD卡）
  // 用户点击“选定当前目录”后调用 LibraryFs.setLibraryRootPath({ path: currentPath })
  return await showPathBrowserModal(state.defaultRoot, state.volumes || []);
}
```
