# v1.10.31 更新说明

**发布日期**：2026-09-26

---

## ✨ 新功能

- **卡片详情「高级设定」全面折叠**：「高级设定」的各个子项默认收起、点击标题展开，每项右侧标出字数 / 条数，长内容不再一次铺满屏幕；超长开场白先折叠预览，点「显示全部」展开、点编辑框自动展开全文；备用开场白的「添加 / 显示全部」按钮移到列表上方，不用再翻到底部。
- **世界书标签**：世界书列表项菜单新增「编辑标签」——可为每本世界书自定义标签（回车或逗号一次加多个，还能从全库已有标签里点选）；列表直接显示标签、顶部可按标签一键筛选。标签只保存在本机配置里，不会改动世界书文件。
- **预设查重**：预设页新增「查重」——自动找出重复预设：名字带「副本 / 备份」的、甚至改了名换了皮的（结构指纹比对）都能发现；分组显示并给出差异证据，可单个或一键把多余版本移入回收站。

## 🐛 问题修复

- **世界书查重找不到「副本」**：用「复制为副本」生成的世界书以前查不到（只认严格同名）——现在会按名称 + 内容双重比对，副本 / 备份 / 改名同源都能被识别为同一组，并标出「完全一致」或重合比例。
- **查重清理可能失败或提示不准**：修复了清理时偶尔提示「移动失败」、明明没清掉却显示已清理的问题；清理 → 回收站找回全链路恢复稳定。
- **世界书查重弹窗有两个关闭按钮** —— 已修复，只保留一个。
