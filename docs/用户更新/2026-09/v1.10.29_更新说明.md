# v1.10.29 更新说明

**发布日期**：2026-09-19

---

## 🐛 问题修复

- **查重弹窗修复**：修复了内容指纹查重完成后弹窗无法关闭的问题
- **主题切换动画**：修复了主题切换时动画丢失的问题，现在切换主题有流畅的动画效果
- **浅色主题色板**：修复了白昼/古风/水墨等浅色主题的组件颜色显示异常问题
- **上下滑动修复**：修复了部分手机上页面无法滑动的问题
- **世界书编辑即时生效**：修复了角色卡内的世界书条目添加/删除后界面不刷新的问题
- **万卡大库稳定性**：修复了超大型卡库（上万张卡片）加载完成后可能闪退的问题
- **世界书保存格式**：修复了角色卡内嵌世界书保存后格式异常、影响外部工具兼容的问题

## ✨ 新功能

- **角色卡世界书整体导入/导出**：在角色卡详情页的「世界书」页签，新增整体导入（从世界书库 / 本地文件 / 网址 / 粘贴文本）与整体导出（保存到世界书库 / 另存为文件），导入时自动跳过重复词条
- **世界书批量管理**：支持多选词条后批量启用 / 停用 / 删除 / 导出所选条目

## 🔧 功能优化

- **模型拉取功能**：TestSidebar 支持协议切换时自动调整 API 端点（与设置页保持一致）
- **内容指纹优化**：内存占用降低，大型卡库也能流畅运行
