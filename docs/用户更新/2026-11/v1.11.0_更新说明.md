# v1.11.0 更新说明

## ✨ 新增功能

### 全盘路径模式（找不到目录 / 重启掉授权时的兜底方案）

部分机型（尤其部分定制系统）的系统文件选择器会出现「打不开目标文件夹」「看不到 Download」「重启后授权失效」等情况，
导致无法选择卡片库目录。本次新增**全盘路径模式**作为兜底：

- 在「设置 → 卡片库 → 全盘路径模式」开启，按提示授予「所有文件访问权限」
- 开启后可用**应用内目录浏览器**直接浏览内部存储、SD 卡、U 盘，选定任意文件夹作为卡片库
- 与原有目录授权方式二选一，随时可在设置里切回
- 该模式需要 Android 11 及以上；Android 10 及以下继续使用原有目录授权方式

> 说明：`Android/data`、`Android/obb` 是其他应用的私有目录，系统本身就不允许任何应用读取，全盘路径模式同样无法访问。
> 卡片请放在「内部存储」下自建的文件夹中（如 `Download/卡库`）。

## 🐛 问题修复

### 选择目录后「扫描到 0 张」的问题

修复了在部分机型上授权库目录成功后却提示「扫描到 0 张」、且没有任何错误提示的问题。现在：

- 扫描不到内容时会**明确说明原因**（目录不可读 / 属于系统受限位置 / 确实是空目录），不再静默显示 0 张
- 修复了多处扫描同时进行时互相干扰、导致某次扫描结果为空的问题

### 系统文件选择器默认位置

打开目录选择器时会**直接定位到「下载」目录**，不用再手动一层层点进去。

### 「上次还能用，这次提示授权失效」

修复了部分机型的目录选择器不返回长期授权、导致重启应用后需要反复重新选择目录的问题。
若确实无法长期保留授权，会在授权时**明确提示**，而不是事后才告知。

### 导入文件夹时界面卡死

修复了「磁盘扫描」导入大量文件时界面卡死、甚至被系统强制关闭的问题。现在扫描在后台进行，界面保持可用并显示进度。

### 按返回键会直接退出应用

修复了在卡片详情页、磁盘扫描等页面按手机返回键会**直接退出整个应用**的问题。现在返回键会正常回到上一页，只有在主页面按返回才会退出。

### 设置页「未授权 · 点击选择」点不动

修复了该提示点击无反应的问题，现在点击即可选择库目录。
