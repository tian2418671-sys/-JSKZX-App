# 一条龙服务 - 每日开发流程

> 每日开发完成后执行，确保代码、文档、发布一条龙完成。

---

## 📋 流程概览

```
┌─────────────────────────────────────────────────────────────┐
│                    📦 每日开发一条龙                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  步骤1: 📂 收集整理                                        │
│  ├── 收集今日更新的数据                                     │
│  ├── 对文档进行归类                                         │
│  │   ├── 内部开发文档 → docs/内部开发/                     │
│  │   └── 用户更新文档 → docs/用户更新/YYYY-MM/             │
│  └── 更新索引文件                                           │
│                                                             │
│  步骤2: 🧪 功能测试                                        │
│  ├── 运行 npm test 确保全部通过                             │
│  ├── 模拟器实测新功能                                       │
│  └── 截图记录关键界面                                       │
│                                                             │
│  步骤3: 🚀 代码推送                                        │
│  ├── git add .                                             │
│  ├── git commit -m "描述"                                  │
│  ├── git push jskapp main-v1.10                           │
│  └── 确保远端同步完成                                       │
│                                                             │
│  步骤4: 📦 发布更新                                        │
│  ├── 构建 APK: npm run build:android                        │
│  ├── 更新版本号                                             │
│  ├── 撰写用户更新文档                                       │
│  └── 提交并推送                                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 🎯 详细步骤

### 步骤 1：收集整理

```bash
# 1.1 收集今日更新的文件
git status

# 1.2 分类整理文档
# 内部开发文档 → docs/内部开发/
# 用户更新文档 → docs/用户更新/YYYY-MM/

# 1.3 更新内部开发 README
# 编辑 docs/内部开发/README.md 添加今日记录
```

### 步骤 2：功能测试

```bash
# 2.1 运行单元测试
npm test

# 2.2 模拟器实测
# 启动模拟器并安装 APK
npm run build:android
adb install -r android/app/build/outputs/apk/debug/app-debug.apk

# 2.3 截图记录
# 截图保存到 docs/内部开发/截图记录/YYYY-MM-DD/
```

### 步骤 3：代码推送

```bash
# 3.1 添加所有更改
git add .

# 3.2 提交（按规范写 commit message）
git commit -m "<type>(<scope>): <subject>

<body>

<footer>"

# 3.3 推送到远端
git push jskapp main-v1.10
```

### 步骤 4：发布更新

```bash
# 4.1 构建 Android APK
npm run build:android

# 4.2 更新版本号
# - package.json: version 字段
# - android/app/build.gradle: versionName + versionCode

# 4.3 撰写用户更新文档
# 创建 docs/用户更新/YYYY-MM/vX.XX.XX_更新说明.md

# 4.4 提交并推送
git add .
git commit -m "chore(release): vX.XX.XX"
git push jskapp main-v1.10
```

---

## 📝 Commit Message 规范

### 格式
```
<type>(<scope>): <subject>

<body>

<footer>
```

### Type 类型

| 前缀 | 说明 | 示例 |
|------|------|------|
| `feat:` | 新功能 | `feat(mobile): 新增卡片库视图切换` |
| `fix:` | BUG 修复 | `fix(mobile): 修复内容指纹 OOM` |
| `perf:` | 性能优化 | `perf(mobile): 内容指纹流式水合` |
| `docs:` | 文档更新 | `docs: 更新用户更新日志` |
| `chore:` | 构建/工具 | `chore: 删除死代码` |
| `refactor:` | 重构 | `refactor: 重构主题切换逻辑` |
| `test:` | 测试 | `test: 新增内容指纹单元测试` |

### 示例

```bash
git commit -m "fix(mobile): 修复浅色主题 Vant 变量损坏

- 修复 light 主题 21 个 --van-* 变量被冒号拼接
- 修复 SettingsView 使用 isDarkTheme 正确判断暗色主题

Closes: #17"
```

---

## ⚠️ 注意事项

1. **用户文档不含代码**：用户更新文档只描述功能变化，不包含代码细节
2. **测试必须通过**：所有 npm test 必须通过才能推送
3. **版本号递增**：每次发布必须更新版本号
4. **截图归档**：实测截图必须保存到对应日期目录

## 🔧 快捷命令

```bash
# 一键测试+构建
npm test && npm run build:android

# 一键 commit+push
git add . && git commit -m "your message" && git push jskapp main-v1.10
```
