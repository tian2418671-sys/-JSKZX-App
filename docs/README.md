## 六、维护约定（总）

1. **文档随代码走**：移动 / 重命名文档后，同步修正 `CHANGELOG.md`、`README.md` 及交叉引用。
2. **新缺陷**：先 `CHANGELOG.md` 段落登记，再（可选）`bugs/` 详述。
3. **新专项**：方案 → `规格与计划/`；实测 → `实测记录/`；技术数据/代码片段 → `技术支持/`。
4. **不收录**：构建产物、`node_modules`、素材文件（第三方插件样例等）。
5. **代码与测试位置**：`js/`（渲染层）、`android/`（Capacitor 工程 + 原生插件）、`test/`（`node --test` 单测）、`scripts/`（探针 / 构建 / 发布脚本）。
