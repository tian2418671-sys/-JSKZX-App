# v1.10.15 千卡秒开性能优化 · 总结报告

> 日期：2026-09-10 · 分支：main-v1.10 · 覆盖缺陷单 #001 闭环

---

## 一、项目背景

SillyTavern 角色卡管理器（移动版，Vue3+Vant+Capacitor，SAF 文件系统）在 1000+ 卡库下：
- 首次扫描 413s（read 344s 占 83% —— SAF 逐路径树查找是根因）
- 二次启动卡片上屏延迟（缓存读取 + 全量 DOM 渲染阻塞主线程）
- 中大图卡片保存/换卡图必失败（writeBuffer 缺失 + spread 溢出两层 Bug）
- 历史内存峰值 350MB+（全量 data 常驻 + 整图 base64 过桥）

## 二、架构级优化（按阶段落地）

### 阶段 1：Quick Win（封面管线 + 保存链路修复）

### 阶段 2：千卡级核心改造（实测驱动）

| 渐进上屏 60 张/批 | 大库一次性 DOM 渲染风暴消除 |

## 五、新增不变量（重构红线）

| # | 不变量 |
|---|---|
| I8 | 桥线程禁止 join/await 长任务；批量原生重活移交后台编排线程 |
| I9 | SAF 路径解析必须走 rescan 期 O(1) 索引；树遍历仅允许 miss 回填 |
| I10 | 大 JSON 的 parse 与条目重建必须在 Worker |
| I11 | 解析超时禁止回退主线程；只允许 resolve(null)+二次机会队列 |
| I12 | 非角色卡必须写负缓存；除强制 refresh 外禁止重复探测 |
