# 预设/世界书外部目录扫描「读取不全」修复 · 模拟器实测记录

- 日期：2026-09-18
- 版本：v1.10.27（versionCode 32，debug 包）
- 设备：JSKZX_Test 模拟器（Android 15 / API 35）
- 应用：`com.sillytavern.cardmanager.android`

## 一、问题现象（用户报告）

预设和世界书「读取不全」：手机上文件之前版本可完整读取，更新后只有个别文件被读取（回归）。

## 二、根因（夹具矩阵复现确认，三类静默丢弃）

| 类别 | 机制 | 影响 |
| --- | --- | --- |
| **UTF-8 BOM 文件** | 记事本等编辑器保存的 JSON 带 `\uFEFF` 头，`JSON.parse` 抛错且被扫描 `catch` 静默跳过 | **主因**：大量文件“消失”（外部扫描与库内解析两条链路均无 BOM 剥离） |
| **>10MB 文件** | `scanWbTree` 跳过阈值 10MB；`readWbText` 读取上限 10MB | 11MB 夹具在扫描列表中整体消失 |
| **>3000 文件** | `scanWbTree` 单次上限 3000 | 超大目录截断（未实际触达，预防性提升） |

对照实验（修复前）：矩阵 31 文件中 `t11_bom.json` / `w06_bom.json` 解析失败被跳过、`t14_huge.json`（11MB）不在扫描列表（count=30）；其余文件读取正常——与“只有个别文件读取”现象一致。

## 三、修复清单（v1.10.27）

1. **BOM 剥离（三层防御）**
   - 外部目录扫描 `scanExternalPresets` / `scanExternalWorldbooks`（`js/bridge/android.js`）：解析前统一 `stripBom`；
   - 原生 `readWbText`（`LibraryFsPlugin.java`）：读取后剥离 BOM（所有消费方一次性受益）；
   - 库内解析链路：`cardParseWorker.js`（Worker）、`useMobileLibrary.js` 的 `parseRawSync`（主线程兜底）、`TestSidebar.vue`「从文件导入」（预设/正则/插件）。
2. **上限提升（`LibraryFsPlugin.java`）**：`scanWbTree` 跳过阈值与 `readWbText` 读取上限 10MB→50MB；单次扫描上限 3000→10000。
3. **静默跳过 → 如实上报**：原生返回 `skippedLarge`；JS 扫描汇总 `skipped`（读取失败 + 解析失败 + 超限）；预设页 / 世界书页 / 测卡预设面板提示「已跳过 N 个无法解析或超限的文件」。

## 四、验证（模拟器实测）

夹具矩阵 31 个文件（正常×10 / BOM×2 / 1.2MB / 11MB / CRLF / 无效件×2 / 嵌套子目录×2 / 角色卡 / 预设缝合夹具×4 等）推送至已授权目录 `Documents/ImportSource`（TestPresets 树无持久授权，改用已授权树验证；首次扫描未授权树的“目录不可读”属预期行为）。

| 验证项 | 结果 |
| --- | --- |
| 原生 `scanWbTree` 枚举 | **31/31**（修复前 30/31，11MB 被吞） |
| 原生 `readWbText` + 裸 `JSON.parse`（验证原生剥离，不依赖 JS 兜底） | **31/31 通过** |
| `t11_bom.json` / `w06_bom.json` | PARSE-FAIL → **PRESET / WB 正常识别** |
| `t14_huge.json`（11MB） | 列表缺失 → **入列表并读取成功（PRESET）** |
| 嵌套子目录 `subdir/` `subdir_wb/` | 均正常识别 |
| JS 封装 `scanExternalPresets` | 19 预设，skipped=0 |
| JS 封装 `scanExternalWorldbooks` | 9 世界书，skipped=0 |
| 预设页 UI 计数 | 「19 个」列表可见（含 t01 测试预设01） |

| `npm test` | **142/142 全绿** |

## 五、遗留与说明

- >50MB 与 >10000 文件量级仍会跳过，但通过 skipped 计数提示，不再静默。
- 无法解析的文件（损坏 JSON）依旧不会进入列表（正确行为），但有计数提示。
- 夹具生成脚本：`shots/preset-scan-test/gen_fixtures.py`（本地测试资产，未入库）。
