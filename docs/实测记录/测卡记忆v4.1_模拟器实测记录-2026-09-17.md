## 二、测试中发现并修复的 2 个真实 Bug（仅运行时暴露）

### BUG-M1：测卡面板整体白屏（模板 ref 误用，本轮 v4.1 引入）

- **现象**：详情页切到「测卡」标签后内容区空白；DOM 中仅 4 个面板（第 5 个未挂载），标签栏高亮正常。
- **根因**：`:current-card-path="card.value.path"` —— Vue 模板中 ref 自动解包，`card` 已是卡片对象，
  `card.value` 为 `undefined` → `undefined.path` 渲染抛错 → 整个面板挂载失败。
- **修复**：改 `card ? card.path : ''`（`CardDetailView.vue`）。
- **复测**：5 个面板齐全，对话/输入/发送全流程正常（截图 01）。
- **教训**：**构建与单测发现不了模板运行时错误**——写模板时误把 script 的 `ref.value` 习惯带进模板，必须真机冒烟。

### BUG-M2：长按动作菜单永远无法触发（迁移期遗留，非本轮引入）

- **现象**：长按卡片无任何反应（多选/移动分组/创建副本/导出/定位/重命名/删除 全部不可达）。
- **根因**：模板绑定 `@longpress="…"`，但**全仓无任何代码派发 `longpress` 事件**；
  `entry.js` 的 `v-longpress` 指令（500ms 定时器 + 点击防穿透 + 震动反馈）**从未被任何模板使用**——手势链路缺最后一段。
- **定位过程**：CDP 手动 `dispatchEvent(new Event("longpress"))` → 菜单立即弹出（证明监听侧正常，只缺派发侧）。
- **修复**：两处卡片元素 `@longpress="…"` → `v-longpress="() => (…)"`（复用现成指令，自带 click 防穿透）。
- **复测**：CDP 触摸长按 650ms → 菜单弹出 →「多选(批量操作)」→ 批量模式正常（截图 04）。
- **备注**：`docs/实测记录/测试日志-2026-09-12.md` 曾两次记录"长按自动化受限"并**假设功能正常**——
  本次证实其真实状态为功能级失效（非仅自动化受限），修复后全链路可用。

## 三、测试方法沉淀（供后续复用）

| 工具 | 用途 | 位置 |
|---|---|---|
| Mock Chat API | 让测卡发送全链路成功；记录 system payload 验证注入块 | `shots/memory-v41/mock-api-server.mjs`（端口 18080） |
| 播种脚本 | 造 v2 格式旧库，验证 schema/数据双层迁移 | `shots/memory-v41/seed_memory_v2.py` |
| CDP 驱动 | 路由导航（`#app.__vue_app__.config.globalProperties.$router`）、DOM 点击、触摸长按（`Input.dispatchTouchEvent`） | `scripts/cdp.js` |

- 生产构建**没有** `__vueParentComponent`（组件实例不可从 DOM 取，需走 router / DOM 事件）。
- 坐标：CSS viewport 412×842，物理 1080×2400（DPR 2.625）；CDP 触摸用 CSS 坐标。
- sqlite 直查引号模式：`adb shell "sqlite3 路径 'SELECT …'"`（外层双引号 + 内层单引号）。
- 模拟器 socket：devtools 为 `webview_devtools_remote_<pid>`（非 `chrome_devtools_remote`）。
- 模拟器启动：AVD 快照损坏时用 `-no-snapshot` 冷启动可绕开；`-no-audio` 提升 Windows 下稳定性；
  从后台终端启动会被终端清理连带杀死，务必用 `Start-Process` 脱离终端。
- **构建路径**：`npm run build:android` 需从真实路径 `E:\AI\酒馆工具\JSK管理APP` 执行；
  从 ASCII junction（`C:\jskapp`）执行时 `cap sync` 会把 `android/capacitor.settings.gradle` 的
  `projectDir` 写成绝对路径（机器相关），提交前需 `git restore` 还原。
