# v1.10.25 两万卡专项测试清单（真机/模拟器验证）

> 本清单覆盖 P0(C1/C2/C3) + A2 + P1(B1/E1/E2/F) + P2(SQlite) 的全部改动。
> 目的：确认改动**不破坏现有功能** + **核心优化路径生效**。
> 预置条件：两份测试卡库——①小库（10-50 张，用于快速功能验证）②大库（如有，用于性能验证）；真机或模拟器（已装 Android 35+）。

## 〇、验收环境准备

1. 安装最新 Debug APK（`npm run build:android` 产物）到设备
2. 准备测试卡目录（含 .json / .png / .webp，至少有空分组 + 子目录 + 1 张带世界书的卡）
3. ADB 已连接（`adb devices` 可见设备）

## 六、异常路径与边界（防崩溃）

| # | 场景 | 操作 | 预期 |
|---|------|------|------|
| 6.1 | 库目录无任何文件 | 授权一个空目录 | 显示"该文件夹未找到角色卡"提示，无崩溃 |

## 七、操作指南速查

```bash
# 安装 APK
adb install -r path/to/app-debug.apk

# 启动 App
adb shell am start -n com.sillytavern.cardmanager.android/.MainActivity

# 清除应用数据（重置到首次状态）
adb shell pm clear com.sillytavern.cardmanager.android

# 查看性能日志
adb logcat -d | grep "\[Perf\]"

# 查看 SQLite 插件日志
adb logcat -d | grep -E "meta|SqliteMeta"

# 查看 A1 批量枚举日志
adb logcat -d | grep "A1 batch cursor"

# 查看 A2 分块调用日志
adb logcat -d | grep -E "scanStart|scanNext"

# 查看缓存/崩溃日志
adb logcat -d | grep -E "FATAL|cache|分片|shard"

# 检查数据库文件
adb shell ls -la /data/data/com.sillytavern.cardmanager.android/databases/

# 检查缩略图磁盘占用
adb shell du -sh /data/data/com.sillytavern.cardmanager.android/files/thumbs/

# 抓截图（存到本地）
adb shell screencap -p /sdcard/test.png && adb pull /sdcard/test.png
```
